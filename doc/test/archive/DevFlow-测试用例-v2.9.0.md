## 1. 测试范围

本版本 v2.9.0 为 DevFlow 框架规则增量版本，涉及 3 个技能文件的规则定义修改。由于 DevFlow 为 Markdown 框架文档项目（非传统软件应用），测试类型作以下适配：

| 测试类别 | 适用性 | 适配说明 |
|:---------|:------:|:---------|
| 测试准备/计划 | ✅ | 必须执行 |
| 环境验证 | ✅ | 文件存在性 + 可读性验证 |
| API 测试 | 🚫 不适用 | 无 API 接口 |
| 集成测试 | ✅ | 跨文件引用一致性验证 |
| E2E 测试 | ✅ | 业务流程走查验证 |
| Mock/外部依赖测试 | 🚫 不适用 | 无外部依赖 |
| 回归测试 | ✅ | 已有规则未被破坏 |
| 覆盖率测试 | ✅ | TD-ID 逐项覆盖率 |
| 合规测试 | ✅ | 文档命名/路径/格式标准 |
| 安全测试 | 🚫 不适用 | 无可执行代码 |
| 性能测试 | 🚫 不适用 | 无性能要求 |
| 可访问性/UI | 🚫 不适用 | 无 UI |
