## 1. 回滚触发条件

| 触发类型 | 条件 |
|:---------|:-----|
| 自动触发 | 技能加载失败 / sync-skills.ps1 报错 / TRAE 平台错误率上升 |
| 手动触发 | P0 技能缺陷 / 规范矛盾 / 兼容性问题 |

## 2. 回滚步骤

| 环境 | 回滚方式 | 命令/操作 |
|:-----|:---------|:----------|
| Dev | git revert | `git revert HEAD` → 恢复至 v2.5.0 |
| Test | git checkout | `git checkout v2.5.0` 获取基线副本 |
| Pro | git revert + tag 保留 | `git revert v2.6.0` 并保留 v2.6.0 tag 用于分析 |

## 3. 数据回滚方案

不涉及数据库（纯 .md 规范文件）。

## 4. 审批流程

| 场景 | 审批人 | 说明 |
|:-----|:-------|:------|
| 标准回滚 | DevFlow 维护团队 | 发布负责人审批 |
| 紧急回滚 | DevFlow 维护团队 | P0 故障 2 小时内补录材料，24 小时内输出 RCA |

## 5. 回滚后验证

| 步骤 | 操作 | 时间要求 |
|:-----|:-----|:--------:|
| 健康检查 | 确认 28 技能文件可正常加载 | 15 分钟内 |
| 冒烟验证 | 验证 TRAE 技能列表包含全部 28 个技能 | 回滚后立即 |
| 复盘 | 输出 RCA 文档 | 24 小时内 |
