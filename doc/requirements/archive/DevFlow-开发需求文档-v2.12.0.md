## 3. 功能需求

### F1: 文件结构一致性门禁（TD-027 / BL-212-001）

| 维度 | 内容 |
|:-----|:------|
| **描述** | 在编码阶段补全文件结构一致性门禁，防止设计文档规划的"新建/重命名/删除"文件操作在编码阶段被静默遗漏 |
| **输入** | 设计文档中的文件操作清单、Backlog Subtask CheckList |
| **处理** | (1) Subtask CheckList 增加命名对齐检查列 (2) code-logic-review 新增第14维度"命名与结构一致性" |
| **输出** | 更新后的 coding-stage-execution.md + code-logic-review.md |
| **涉及文件** | `devflow-plugin/skills/L2/coding-stage-execution.md`, `devflow-plugin/skills/L3/code-logic-review.md`，对应 .trae 副本 |
| **验收标准** | Subtask CheckList 包含"命名与设计一致"检查项；code-logic-review 第14维度可执行 |

### F2: 风险归集门禁完整落地（TD-026 / BL-212-002）

| 维度 | 内容 |
|:-----|:------|
| **描述** | 在 6 个 L2 主控技能的移交步骤中增加"风险归集检查清单"强制步骤 |
| **输入** | 当前 6 个 L2 技能文档中的移交步骤 |
| **处理** | 在 version-planning/requirements/design/coding/testing/operations 6 个 L2 技能的移交步骤中增加风险归集检查清单模板 |
| **输出** | 6 个 L2 技能文档更新 |
| **涉及文件** | 6 个 L2 SKILL.md + 对应源文件 |
| **验收标准** | 每个 L2 技能移交步骤包含风险归集检查表，audit-agent 可独立验证 |

### F3: 性能基准测试（TD-011 / BL-212-003）

| 维度 | 内容 |
|:-----|:------|
| **描述** | 创建性能基线模板和基线文档框架 |
| **输入** | DevFlow 技能加载/配置读取等关键操作 |
| **处理** | 创建 doc/performance/ 基线文档，定义 P0 功能性能基线采集方法 |
| **输出** | 性能基线文档 + 模板 |
| **涉及文件** | `doc/performance/DevFlow-性能基线-v2.12.0.md` |
| **验收标准** | 基线文档包含 P50/P99/吞吐量指标和采集方法 |

### F4: 技能引用统一注册（TD-025 / BL-212-004）

| 维度 | 内容 |
|:-----|:------|
| **描述** | 为 138 个未注册的技能引用建立统一注册机制 |
| **输入** | validate-install.ps1 C08 检查结果 |
| **处理** | (1) 创建 validate-registry.ps1 自动扫描脚本 (2) 逐项补全 138 个引用到 devflow-config.json |
| **输出** | validate-registry.ps1 + 更新后的 devflow-config.json |
| **涉及文件** | `devflow-plugin/validate-registry.ps1`, `devflow-plugin/devflow-config.json` |
| **验收标准** | validate-registry.ps1 运行结果零未注册引用 |

### F5: config.json 改名遗留（TD-029 / BL-212-005）

| 维度 | 内容 |
|:-----|:------|
| **描述** | 执行 v2.9.1 设计规划但被静默遗漏的 `.devflow/config.json → project-config.json` 重命名 |
| **输入** | 当前 `.devflow/config.json` |
| **处理** | (1) 文件重命名 (2) 更新所有 L2 和 .trae 副本中的硬编码路径引用 (3) devflow-init 生成路径更新 (4) state.json 引用路径更新 |
| **输出** | 重命名后的文件 + 15 处引用更新 |
| **涉及文件** | `.devflow/project-config.json`, 6 个 L2 技能文档 + 对应 .trae 副本 |
| **验收标准** | 无任何技能文档引用旧路径 `.devflow/config.json` |

### F6: 设计评审维度增强（IMP-001 / BL-212-006）
