## 1. 业务目标

| 目标 | 内容 |
|:-----|:------|
| **业务目标** | 统一 DevFlow 跨项目命名规范，消除硬编码项目名；发布阶段标准化管理 |
| **用户目标** | 用户指南/手册伴随发布同步更新，用户可获取最新版本文档 |
| **技术目标** | config.json 改名遗留执行、三远程备份规范定稿、发布产物标准化命名 |
| **成功指标** | 所有 `{项目名}` 占位符替换为变量引用；用户指南/手册纳入发布交付物门禁 |

## 2. 功能需求

### 2.1 V2100-004：跨项目文件命名规范化

| 字段 | 内容 |
|:-----|:------|
| **ID** | V2100-004 |
| **优先级** | 🟡 P1 |
| **关联债务** | TD-029（config.json 改名遗留） |
| **描述** | 将 `.devflow/config.json` 重命名为 `.devflow/project-config.json`；全局文档模板中 `DevFlow-` 前缀改为 `{项目名}-` 变量引用 |
| **具体子项** | ① 重命名 `.devflow/config.json → .devflow/project-config.json`，同步所有引用路径 ② 全局文档模板全部改为 `{项目名}-` 格式 ③ Changelog 统一用 `{项目名}-Release-Note-All.md` 替代 `README.md` ④ 更新 6 个 L2 技能文档及 SKILL.md 副本中的硬编码路径 |
| **验收标准** | 重命名后项目正常运行；所有技能文档中 `DevFlow-` 前缀引用替换为变量 |
