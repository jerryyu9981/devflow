## 1. 部署策略

| 维度 | 内容 |
|------|------|
| 部署方式 | Git tag + push 双仓库同步 |
| 发布单元 | 全量框架文件（技能 + 文档 + 配置） |
| 发布频率 | 按版本迭代节奏（非持续发布） |
| 发布窗口 | Step 5 部署当天 |
| 回滚策略 | `git revert tag` + 重新发布 |

**与 v2.8.5 差异**：无变化。部署策略与 v2.8.5 保持一致。

## 2. 环境配置

| 环境 | 用途 | 仓库 |
|:----:|------|:----:|
| origin | 主仓库，开发/发布使用 | 远程仓库地址 1 |
| backup | 备份仓库，冗余同步 | 远程仓库地址 2 |

**与 v2.8.5 差异**：无变化。远程仓库地址已配置。

## 3. 发布流程

Step 5 启用后参考 `DevFlow-发布计划-v2.9.0.md`。

## 4. 兼容策略

| 兼容维度 | 策略 |
|---------|------|
| 文件结构 | 不改变现有文件路径和命名 |
| 技能调用 | 全部增量修改，不改变现有接口 |
| 配置格式 | 保持 .devflow/config.json 格式不变 |
| 债务总表格式 | 保持 15 字段标准格式，仅补充 BL-ID 列 |
