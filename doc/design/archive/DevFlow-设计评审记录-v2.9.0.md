```markdown
(5) 计算还债占比 = 本版本还债数 / 本版本总需求数
```

### 3.2 技能修改规格 — testing-stage-execution.md（R-03, R-04）

**修改位置**：测试阶段门禁章节插入覆盖率门禁规则，新增 E2E 验证章节。

**覆盖率门禁规则**：

```markdown
### 覆盖率门禁
- 新代码行覆盖率目标：>=80%
- 阻塞条件：覆盖率 <80%
- 阻塞处理：输出未覆盖代码清单 + 要求补充测试 + 重测
- 通过条件：覆盖率 >=80%
```

**E2E 验证流程**：

```markdown
### E2E 集成验证
Step 4 启动时执行：
1. 读取本版本 E2E 验证场景列表
2. 每个场景按定义执行
3. 全部通过 → 输出验证通过报告
4. 存在失败 → 记录失败场景 + 要求修复重测
```
