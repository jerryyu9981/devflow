## 2. v2.4.0/v2.4.1：全面迭代 + Hotfix ✅ 已完成

**实际发布**：v2.4.0 (2026-07-02) + v2.4.1 Hotfix (2026-07-03)

## 4. v2.5.0 → v3.0.0：架构升级

**发布目标**：2027 年 Q2（6 月底）

**版本主题**：架构升级 — 智能化 + 可观测 + 多语言

### 4.1 版本目标

| 维度 | 目标 |
|---|---|
| **架构** | 技能架构插件化，支持热加载和按需加载 |
| **智能化** | 基于项目特征自动推荐技能组合 |
| **可观测性** | 内置开发流程度量仪表盘 |
| **多语言** | 全部技能文件支持中英双语 |

### 4.2 核心方向（规划中）

| 方向 | 描述 | 优先级 |
|---|---|---|
| **插件化架构** | 技能文件独立为可插拔模块，支持版本化管理 | P0 |
| **智能推荐** | 分析项目类型/技术栈/规模，推荐最佳技能组合 | P1 |
| **可观测性** | 开发流程质量度量、效率统计、合规检查仪表盘 | P1 |
| **多语言** | 全部技能和模板支持中文/英文双语 | P1 |
| **API 抽象层** | 抽象平台相关 API，新增平台只需实现适配层 | P1 |

### 4.3 预期成果

| 成果类型 | 描述 |
|---|---|
| **架构** | 插件化技能架构，支持第三方技能扩展 |
| **智能** | 项目特征识别 + 技能自动推荐 |
| **可观测** | 质量仪表盘（HTML） |
| **多语言** | 中英双语技能文件 |

## 6. 风险与依赖

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| v2.4.0 范围过大导致延期 | 13 项需求可能超出容量 | 严格执行优先级，P2 可降级到 v2.5.0 |
| 跨平台兼容问题超预期 | 部分平台兼容性不达标 | 降低 Codex CLI 目标到 ★★★☆☆ |
| TRAE 技能市场规范变更 | v2.5.0 技能市场集成受阻 | 提前与技能市场团队对齐规范 |
| v3.0.0 架构重构风险 | 可能影响已有技能兼容性 | 提供迁移工具和过渡期 |
