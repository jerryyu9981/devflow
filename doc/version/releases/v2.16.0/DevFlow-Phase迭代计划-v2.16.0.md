## 2. Phase 1：网络层信号采集与分类

| 项 | 内容 |
|:---|:-----|

| 验收 | 8 类信号表 + 9 类分类表存在；用 BUG-291-012（竞态 500 → B 类）与 /local-models 503（Ollama → H 类）演练判定正确 |

## 3. Phase 2：断言门禁与 E2E 订阅

| 项 | 内容 |
|:---|:-----|

| BL-ID | BL-216-001（IMP-3 + IMP-4 + IMP-8）|
| 任务 | ① "页面可达≠请求成功≠功能正确"写入禁止模式 ② attach_network_listeners + assert_network_clean 代码模板入 E2E 章节 ③ T3b/E2E 断言模板强制调用 ④ T3 通过标准补充门禁项 |

| 验收 | L3 断言为强制；模板含 H/I 类过滤；模拟代码类 500 门禁不通过 |
