## 6. 发布策略草案

- **类型**：次版本
- **影响范围**：testing-stage-execution、api-contract-management、code-version-backup-management、devflow-init（4 个技能文档）+ Stage4 产出物清单 + release.ps1 + validate-version-header.ps1（2 个脚本）
- **总工作量**：~582 行变更（470+50+12+30+20）
- **发布窗口**：2026-08
- **回滚策略**：Git revert 到 v2.14.0 tag；技能文档回退到 v2.14.0 版本
- **兼容策略**：T1-T4 架构为增量增强，不破坏现有测试流程；版本号同步为流程增强，向后兼容
- **灰度策略**：DevFlow 为规范框架，无灰度需求；发布后全量推送 IDE 技能
