## 优先级评估方法

| 方法 | 说明 |
|:-----|:-----|
| 评估维度 | 价值（规范完整性）+ 成本（工作量）+ 风险（不确定性） |
| P0 判定 | 跨阶段衔接空白，影响 Step 2→3→4 全链路 |
| P1 判定 | 规范内部矛盾或遗留未闭合，需本版本修复 |
| P2 判定 | 模板配套补齐，非阻塞但有配套价值 |
