## 1. Phase 总览

v2.4.0 拆分为 4 个 Phase，按依赖关系和优先级排序：

```
Phase 1: 基础建设 ──→ Phase 2: 体验升级 ──→ Phase 3: 能力扩展 ──→ Phase 4: 兼容验证
  (3 周)                (3 周)                (2 周)                (2 周)
  │                      │                      │                      │
  规范制定              安装优化              技能补全              跨平台测试
  质量审查              初始化增强              + 最终发布
```

| Phase | 名称 | 周期 | 需求数 | 工时估算 | 关键里程碑 |
|---|---|---|---|---|---|
| **Phase 1** | 基础建设 | 第 1~3 周 | 4 项 | 10 人天 | 编写规范发布 + 质量审查完成 |
| **Phase 2** | 体验升级 | 第 4~6 周 | 4 项 | 11.5 人天 | 安装向导可用 + 初始化增强完成 |
| **Phase 3** | 能力扩展 | 第 7~8 周 | 3 项 | 9 人天 | 新增 5+ 个技能/模板 |
| **Phase 4** | 兼容验证 | 第 9~10 周 | 4 项 | 7 人天 | 全平台验证通过 + GA 发布 |

**总周期**：10 周（含 2 周缓冲分布在各 Phase 中）
**缓冲策略**：每个 Phase 内含 1~2 天缓冲，Phase 4 末尾预留 3 天回归测试

## 6. 关键依赖关系

```
VR-012 (编写规范)
  └──→ VR-011 (质量审查，需要规范作为审查标准)
        └──→ VR-013 (交叉引用检查，需要审查结果)

VR-018 (安装脚本统一)
  └──→ VR-001 (安装向导，依赖统一脚本)
        └──→ VR-005 (安装验证，依赖安装向导)

VR-012 (编写规范)
  └──→ VR-006, VR-007, VR-009 (新技能开发，需要按新规范编写)

VR-001, VR-002 (安装+初始化)
  └──→ VR-015, VR-016, VR-017 (跨平台测试，需要完整安装体验)

VR-003 (快速入门)
  └──→ VR-001 (安装向导完成后才能编写准确的教程)
```

## 7. 风险应对

| 风险 | 影响的 Phase | 应对措施 |
|---|---|---|
| Phase 1 质量审查发现大量问题 | Phase 1 延期 | 延伸缓冲到 Phase 2 第一周 |
| 安装向导跨平台问题多 | Phase 2 延期 | 降低 P2 的 VR-017 优先级 |
| 新技能内容编写质量不达标 | Phase 3 延期 | VR-007 拆分为安全编码 + 安全测试两个独立交付 |
| 跨平台兼容问题超预期 | Phase 4 延期 | Codex CLI 适配可推迟到 v2.4.1 |
