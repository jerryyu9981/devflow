## 1. 版本背景

v2.9.1 发布后，devflow-init 初始化检测发现 3 个配置文件不一致问题：
1. 项目根 `version.json`（v2.8.5）与 `devflow-config.json`（v2.9.1）版本号不一致
2. `.devflow/config.json` 中 `projectVersion`（2.9.0）与 Git Tag（v2.9.1）不一致
3. `devflow-plugin/` 下保留已弃用的 `version.json`（v2.8.5）和 `devflow-manifest.json`，与源 `devflow-config.json`（v2.9.1）不一致

这些问题本质是 v2.9.0/v2.9.1 配置体系重构后，旧配置文件未完全清理导致的配置漂移。v2.9.2 定位为**配置一致性修复版本**，解决上述遗留问题并为 v2.10.0 的大规模还债（TD-024/025/026）做准备。

## 2. 版本目标

### 2.1 业务目标
- 消除 DevFlow 插件配置体系中的版本号不一致问题，确保 devflow-init 检测无告警

### 2.2 用户目标
- 用户运行 devflow-init 时不再看到版本不一致提示
- 新安装用户不再看到已弃用配置文件

### 2.3 技术目标
- 项目根 `version.json`、`.devflow/config.json`、`devflow-config.json` 三者版本号一致
- 已弃用配置文件按迁移指南备份后清理
- 风险归集门禁前置准备（TD-026 部分偿还）

### 2.4 成功指标
| 指标 | 目标值 | 验证方式 |
|:-----|:------:|:---------|
| devflow-init 版本检测结果 | consistent（一致） | 运行 devflow-init 检查 versionCheck.result |
| 配置文件一致性 | 3 个配置文件版本号全部为 2.9.2 | 人工核对 |
| 已弃用文件清理 | devflow-plugin/version.json 和 devflow-manifest.json 已备份+删除 | LS/Glob 验证 |
| 候选需求池更新 | 新增 V292-001~003，状态标记正确 | 读取候选需求池验证 |
