## 2. Phase 拆分

### Phase 1: 体验优化

| 项 | 内容 |
|---|---|
| **时间范围** | 2026-07 上旬 ~ 中旬（1–2 周） |
| **负责需求** | VR-019（devflow-init 远程仓库交互式配置） |
| **优先级** | P1（成本低） |
| **预估工期** | 1 人周 |

**交付物**

- 增强的 `devflow-init / SKILL.md`，支持交互式远程仓库配置

**验收重点**

1. 交互界面明确区分 **DevFlow 下载地址** 与 **用户项目 Git 远程仓库地址**
2. 配置正确写入 `config.json`

---

### Phase 2: 能力扩展

| 项 | 内容 |
|---|---|
| **时间范围** | 2026-07 中旬 ~ 8月下旬（4–5 周） |
| **负责需求** | VR-008（性能工程全流程技能）+ VR-010（数据库迁移管理技能） |
| **优先级** | P2（内容量较大） |
| **预估工期** | 3–4 人周 |

**交付物**

- 新增 2 个 L3 技能文件：性能工程、数据库迁移管理

**验收重点**

1. 性能工程：5 个核心章节完整
2. 数据库迁移：支持 3 种数据库
3. L2 速查表补充

---

### Phase 3: 生态集成与兼容

| 项 | 内容 |
|---|---|
| **时间范围** | 2026-09 ~ 10（4–5 周） |
| **负责需求** | VR-004（技能市场集成）+ VR-017（Codex CLI 深度适配） |
| **优先级** | P2（涉及外部依赖） |
| **预估工期** | 3–4 人周 |

**交付物**

- 技能市场元数据文件
- Codex CLI 兼容性报告和修复

**验收重点**

1. 技能市场成功上架
2. Codex CLI 核心流程通过

**风险**

| 风险项 | 说明 |
|---|---|
| 技能市场规范变更 | TRAE 技能市场上架规范可能在开发期间更新，需预留适配时间 |
| Codex CLI 功能模型不稳定 | Codex CLI 本身处于快速迭代阶段，适配接口可能变更，需保持跟踪 |

每个 Phase 预留 **15–20%** 容量用于技术债务偿还，具体包括：

- 重复内容收敛与引用重构
- 过期示例更新与断链修复
- 技能文件元数据（frontmatter）补全
