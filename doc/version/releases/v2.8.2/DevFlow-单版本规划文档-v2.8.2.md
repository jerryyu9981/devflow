## 1. 版本目标

v2.8.2 为安装流程修复 + 健壮性增强版本，核心目标是：将 install.ps1 的下载步骤对齐到 download-devflow.ps1（消除功能重复），补齐首次安装的仓库地址引导交互，修复 UTF-8 BOM 导致技能无法加载的 P0 问题，并提升 IDE 目录配置的灵活性。

### 1.1 核心目标

1. **install.ps1 下载步骤对齐 download-devflow.ps1**（V260-047）：消除 install.ps1 中约 100 行内联 git clone 逻辑，改为调用 download-devflow.ps1，统一下载职责
2. **install.ps1 首次安装时引导设置下载仓库地址**（V260-048）：repository 为空时自动引导用户设置，并支持 `-TargetDir` 参数指定本地副本目录
3. **安装后自动去除 SKILL.md 的 UTF-8 BOM 头**（V260-050）：防止 TRAE Write 工具引入的 BOM 导致技能无法被扫描器识别
4. **IDE 系统目录可配置化**（V260-049）：通过 `DEVFLOW_SKILLS_DIR` 环境变量支持非标准 TRAE 安装路径

### 1.2 版本范围

**包含**：V260-047、V260-048、V260-049、V260-050

**不包含**（后续版本）：
- V260-039~043：全自动循环架构（目标 v2.9.0，需预研）
- V260-001~005：Agent 协作协议、自动化审计等（需预研）
- V260-001~005 延续项：追溯链可视化、并行阶段执行、国际化模板

### 1.3 版本规划说明

> v2.8.2 的 4 项需求全部围绕"安装流程三步走对齐"这一主题。V260-047 和 V260-048 是 P0 级别，解决 install.ps1 与 download-devflow.ps1 的功能重复和首次安装引导缺失问题；V260-050 是 P0 级别，解决 v2.7.3~v2.8.1 开发过程中暴露的 BOM 头导致技能无法加载的实际故障；V260-049 是 P1 级别，提升非标准 TRAE 安装路径的兼容性。
>
> 本版本不涉及 SKILL.md 技能内容变更，仅涉及安装/更新/同步脚本（.ps1/.sh/.bat）。
