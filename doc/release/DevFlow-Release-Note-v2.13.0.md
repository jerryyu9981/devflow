# DevFlow Release Note — v2.13.0

> 文档类型：单版本发布说明
> 版本：v2.13.0
> 日期：2026-07-27

---

## 概述

v2.13.0 为**治理精细化版本**。围绕发布流程闭环、文档规范统一和门禁体系增强，完成 6 项改进项。同时包含 devflow-phase-manager 审计报告硬门禁的架构级修复。

## 变更清单

### BL-213-001：阶段产出物清单审计门禁

在 6 阶段（Step 0~5）各嵌入阶段产出物 checklist，确保每阶段交付物完整。audit-agent 能力升级（能力2），支持：
- 阶段产出物逐项核查
- 缺失产出物自动阻断
- 审计报告包含产出物覆盖率统计

### BL-213-002：文档命名统一核查

新增 `validate-naming.ps1` 脚本，对项目文档命名进行统一核查：
- 检查文件名是否符合 `{文档类型}-{标题}-v{版本}.md` 规范
- 扫描全项目文档路径，输出不合规列表
- 提供自动修复建议

### BL-213-003：用户指南/手册模板规范化

用户指南和用户手册模板标准化：
- 统一章节结构（概述→安装→使用→FAQ→附录）
- 规范 Markdown 格式和表格样式
- 预填版本号和日期占位符

### BL-213-004：Release Note 双文件对齐

Release-Note-All 模板更新，确保：
- Release Note 与 Changelog 信息一致
- 变更清单、版本日期、关联需求双向对齐
- 自动校验脚本同步更新

### BL-213-005：路线图同步纳入发布门禁

Release Checklist 新增发布门禁项：
- 发布前必须确认路线图已更新
- 路线图状态与实际发布状态一致
- 版本间依赖关系同步更新

### BL-213-006：release.ps1 master 分支推送补齐

release.ps1 脚本增强：
- 新增 master 分支推送步骤
- 确保 tag 同时推送至 origin 和 backup
- 发布后验检查包含 master 分支同步确认

### 架构级修复：devflow-phase-manager 审计报告硬门禁

- 修复 devflow-phase-manager 在审计报告缺失时未硬性阻断的问题
- 阶段状态切换前强制检查审计报告存在性
- 审计报告不完整时拒绝状态推进

## 升级影响
- **无**。所有变更为技能文档规则增强、脚本新增和门禁补充，**完全向后兼容**。
