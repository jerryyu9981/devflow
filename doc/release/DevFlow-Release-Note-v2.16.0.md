## 变更内容

### 1. 🛡️ 测试巡检网络层监控规范增强（V216-001，P0）

基于 OpenLLM v2.9.1 使用反馈（BUG-291-012 竞态 500 漏检至人工测试），将 T3a 巡检与 E2E 的网络层健康监控固化为 Step 4 标准动作，8 项改进：

| 序号 | 改进项 | 说明 |
|:----:|:-------|:-----|
| ① | T3a 巡检信号表 6→8 类 | 拆分 HTTP 4xx/5xx + 新增 requestfailed + 5xx 响应体摘要采集 |
| ② | 问题分类 7→9 类 | 新增 H 类环境提示 / I 类弃用警告 + 判定优先级流程 |
| ③ | L4 网络层断言强制 | "页面可达≠请求成功≠功能正确"写入禁止模式 4 |
| ④ | E2E 网络层事件订阅标准动作 | attach_network_listeners + assert_network_clean 代码模板入规范 |
| ⑤ | 偶发缺陷多轮巡检策略 | ≥3 轮快速巡检 + 跨轮比对（BUG-291-012 经验固化）|
| ⑥ | 根因定位手段 6→7 种 | 新增并发/时序复现 |
| ⑦ | 巡检输出物标准 | 逐页问题表扩展字段 |
| ⑧ | 门禁明确化 | 代码类 ≥500=0 / requestfailed=0 / console error=0 |

### 2. 🔍 审计执行确定性加固（V216-002，P1）

| 项 | 内容 |
|:---|:-----|
| 来源 | v2.13.0 复盘候选 V213-001 正式纳入 |
