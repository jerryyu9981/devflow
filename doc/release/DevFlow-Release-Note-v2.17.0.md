### 原型设计衔接规范（V216-006/007/008）

- **原型设计 IN/OUT 衔接规范建立**：design-stage-execution 新增"原型设计 IN/OUT 衔接规范"章节，定义 3 种场景导入协议（Figma 外部工具/独立设计/已有原型接入）+ 下游移交增强（原型文件清单 + DT-ID 映射 + 交互状态清单）+ E2E 原型状态断言基线

- **原型设计说明章节模板**：project-document-templates 新增 5 项最小内容模板（来源/页面 RT-ID 映射/交互状态/文件路径/覆盖率引用）

### SPEC-291 遗留闭合（V216-003/004/005）

- **T3a 全页面巡检标记修正**：全栈项目从 [按需] 改为**强制**（工作流图/步骤表/通过标准/L4 断言/定义 5 处一致），纯后端以服务间集成巡检替代
- **网络层巡检自动化演进预研**：预研报告结论 ✅ 可行，建议 v2.18.0 实施（Playwright E2E 用例模板 + CI 集成 + 自动报告）
