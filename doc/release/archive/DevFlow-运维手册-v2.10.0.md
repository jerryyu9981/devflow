## 2. 常见故障

| 故障 | 原因 | 排障命令 |
|:-----|:-----|:---------|
| 技能未加载 | 未执行 update.ps1 | `.\update.ps1 -Action Sync` |
| 技能版本不对 | devflow-config.json 版本落后 | 检查 `devflowVersion` 字段 |
| 配置文件格式错误 | 手动修改 JSON 语法错误 | `ConvertFrom-Json` 语法检查 |
