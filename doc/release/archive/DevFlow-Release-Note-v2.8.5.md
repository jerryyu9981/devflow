# DevFlow Release Note v2.8.5

> **版本**: v2.8.5
> **发布日期**: 2026-07-20
> **版本主题**: 债务生命周期管理 + 发布自动化 + 跨版本连续性

---

## 一句话介绍

v2.8.5 建立了完整的债务生命周期管理闭环（发现→记录→审查→老化→偿还），标准化了 Release Note + Changelog 发布文档体系，实现了自动化发布脚本，并确保跨版本风险和债务不遗忘、可接续。

## 为什么升级

- **债务不再丢失** — 风险归集门禁嵌入全部 4 个 L2 阶段技能，每个阶段完成后自动归集 P1+ 风险到全局债务总表，不再遗漏
- **版本启动自动审查** — 新增 0.0a 跨版本债务审查节点，每版本启动时自动读取待偿还债务、执行老化升级、输出 Backlog
- **发布标准化** — Release Note + Changelog 机制固化为 Step 5 必出文档，用户可追溯每个版本的变更内容
- **发布自动化** — `release.ps1` 脚本提供版本校验→Tag→双远程推送→后验的自动化流水线
- **发布有清单** — 13 项 Release Checklist 覆盖发布前/中/后全流程，避免遗漏

## 怎么升级

```bash
# 1. 更新到最新版本
git pull origin main

# 2. 确认版本号
cat devflow-plugin/version.json  # 应显示 2.8.5

# 3. 查看完整变更
git log v2.8.4..v2.8.5 --oneline
```

## 注意事项

- `version.json` 的 `devflowVersion` 字段已从 2.8.4 更新至 2.8.5
- 本版本无破坏性变更，向后兼容
- `devflow-init` 的远程仓库交互输入在已有配置时会自动跳过（向后兼容）
- 新的风险归集门禁在下一版本（v2.8.6+）首次生效时会自动检测已有债务
