# DevFlow Release Note — v2.11.0

> 文档类型：单版本发布说明
> 版本：v2.11.0
> 日期：2026-07-27

---

## 概述

v2.11.0 引入 `audit-agent` 独立审计师技能，将 DevFlow 的审计机制从"形式核验"升级为"独立复审"。同时将审计断言嵌入 6 个 L2 主控技能的移交步骤，实现全流程审计自动化。

## 变更清单

### 新增技能

| 文件 | 说明 |
|:-----|:------|
| `devflow-plugin/skills/L3/audit-agent.md` | 独立审计师技能（548 行），4 项审计能力 |
| `devflow-plugin/.trae/skills/audit-agent/SKILL.md` | .trae 副本 |

### 审计能力

| 能力 | 内容 |
|:-----|:------|
| **能力 1** | 追溯链独立验证（RT→DT→TD→TT→全链汇总） |
| **能力 2** | 产出物独立盘点 + 子步骤完整性验证（检测 LLM 跳步） |
| **能力 3** | 关键检查点复查（22 项，含仓库备份验证 + 证据真实性判定） |
| **能力 4** | 审计报告自动生成（8 章节，含风险归集检查） |
