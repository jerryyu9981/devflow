## 1. 回滚预案

### 1.1 回滚策略

| 部署项目 | 回滚方式 |
|:---------|:---------|
| 文档/配置类变更 | `git checkout v2.9.2` 恢复旧版本文件 |
| 脚本类变更（update.ps1） | `git checkout v2.9.2 -- devflow-plugin/update.ps1` |
| 模板变更 | `git checkout v2.9.2 -- devflow-plugin/templates/` |
| devflow-config.json 变更 | `git checkout v2.9.2 -- devflow-plugin/devflow-config.json` |

### 1.2 触发条件

| 触发条件 | 级别 | 说明 |
|:---------|:----:|:------|
| update.ps1 执行后无法安装技能 | P1 | 脚本回归失败 |
| devflow-config.json 格式错误导致技能加载失败 | P1 | 配置损坏 |
| validate-registry.ps1 在回滚后失败 | P2 | 引用不一致 |

### 1.3 审批流程

| 场景 | 审批人 |
|:-----|:-------|
| 标准回滚（Dev 环境） | PM-DevFlow-Dev（自决） |
| 紧急回滚（P0 故障，跳过审批） | 2 小时内补录材料 |
