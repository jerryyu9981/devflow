## 7. 经验总结

1. **PS1 编码规范必须前置**：PowerShell 5.1 对 UTF-8 无 BOM 文件会按 ANSI 解析，导致中文乱码。后续所有 PS1 文件必须在 CI 中检查 BOM。
2. **直接写入优于 subagent**：subagent 创建文件可能静默失败，关键文件应直接使用 Write 工具。
3. **测试脚本应纳入版本管理**：check-skill-format.ps1 等脚本自身也需要格式检查，避免"检查工具自身有问题"。
4. **旧文件格式标准化需渐进推进**：22 个旧文件格式偏差不影响功能，但应纳入中长期改进计划。
