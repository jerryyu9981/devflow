# archive — 归档区

| 子目录 | 内容 | 说明 |
|:-------|:-----|:-----|
| `history/` | 旧版插件副本 | devflow-plugin-v2.1.0 / v2.3.1 / v2.3.2 / v2.4.0、devflow-plugin-history、devflow-plugin-historys、install-devflow-v2.3.1.ps1 |
| `backup/` | 仓库备份残留 | .devflow.bak-20260703_093545 等 |

| `marketing/` | 营销物料 | DevFlow-手机版介绍卡片（html/png）、DevFlow-抖音短视频脚本 |
| `skill-sources/` | 旧技能源文件 | 早期 L2/L3 技能 md（现行版本在 devflow-plugin/skills/）|

## 归档规则

- 归档区内容**只读**，禁止修改。
- 历史版本文档的正式归档位置在各自 `doc/` 子目录的 `archive/` 下（见根目录 README「文档归档规则」）。
- 本目录为仓库级集中归档区，收纳无法归入 doc/ 子目录的过程性产物。
