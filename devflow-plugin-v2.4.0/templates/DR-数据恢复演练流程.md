## 3. 演练场景定义

### 3.1 场景一：单组件故障恢复

| 属性 | 描述 |
|------|------|
| 场景编号 | DS-001 |
| 场景名称 | 单组件故障恢复 |
| 模拟故障 | {组件名，如 MySQL 主库} 宕机，服务不可用 |
| 演练目标 | 验证单组件的故障检测、自动切换和手动恢复能力 |
| 演练类型 | 组件演练 |
| 预计时长 | 1小时 |
| 影响范围 | 隔离环境，不影响生产 |
| 恢复目标 | RTO <= {15分钟}，RPO = 0 |

**模拟步骤**：
1. 在隔离环境中停止目标组件
2. 验证监控系统是否在 {30秒} 内触发告警
3. 执行恢复操作（主从切换 / 重启 / 从备份恢复）
4. 验证服务恢复正常
5. 记录实际恢复时间

### 3.2 场景二：全量数据恢复

| 属性 | 描述 |
|------|------|
| 场景编号 | DS-002 |
| 场景名称 | 全量数据恢复 |
| 模拟故障 | 数据库数据全部丢失，需要从最近的全量备份恢复 |
| 演练目标 | 验证全量备份的可恢复性和恢复流程的正确性 |
| 演练类型 | 组件演练 / 实战演练 |
| 预计时长 | 2-4小时 |
| 影响范围 | 隔离环境 |
| 恢复目标 | RTO <= {2小时}，RPO <= {24小时}（依赖全量备份时间） |

**模拟步骤**：
1. 在隔离环境中清除全部数据库数据
2. 从最近的全量备份中恢复数据
3. 应用后续增量备份
4. 验证数据完整性（记录数、校验和、关键业务数据）
5. 启动应用服务并验证功能

### 3.3 场景三：跨地域切换

| 属性 | 描述 |
|------|------|
| 场景编号 | DS-003 |
| 场景名称 | 跨地域故障切换 |
| 模拟故障 | 主地域完全不可用，需要将所有服务切换到从地域 |
| 演练目标 | 验证跨地域切换流程、DNS 切换和回切流程 |
| 演练类型 | 实战演练 |
| 预计时长 | 4-8小时 |
| 影响范围 | 仅影响演练环境或使用流量影子模式 |
| 恢复目标 | RTO <= {15分钟}，RPO <= {5分钟} |

**模拟步骤**：
1. 模拟主地域故障（停止主地域所有服务）
2. 按照切换流程执行从地域提升
3. 更新 DNS 和负载均衡器配置
4. 验证从地域服务正常
5. 执行数据一致性验证
6. 模拟主地域恢复后执行回切
7. 验证回切后服务正常

### 3.4 场景四：勒索病毒恢复

| 属性 | 描述 |
|------|------|
| 场景编号 | DS-004 |
| 场景名称 | 勒索病毒恢复 |
| 模拟故障 | 生产环境数据被加密，需要从干净的备份恢复，同时清除病毒 |
| 演练目标 | 验证安全事件下的恢复流程、备份隔离性和恢复效率 |
| 演练类型 | 桌面推演 / 实战演练 |
| 预计时长 | 桌面2小时 / 实战4-8小时 |
| 影响范围 | 桌面推演无影响 / 实战演练仅影响隔离环境 |
| 恢复目标 | RTO <= {4小时}，RPO <= {最近一次干净的备份} |

**模拟步骤**：
1. 在隔离环境中模拟数据被加密
2. 评估受影响范围（哪些数据被加密）
3. 确认最近干净的备份点（未被加密的备份）
4. 从干净备份中恢复数据
5. 扫描并清除残留威胁
6. 验证恢复后的系统安全性和数据完整性

## 5. 演练结果评估标准

### 5.1 评估指标体系

| 评估维度 | 指标 | 计算方式 | 权重 | 合格标准 | 优秀标准 |
|---------|------|---------|:----:|---------|---------|
| 时间达成 | RTO 达成率 | 实际RTO <= 目标RTO ? 100% : (目标/实际*100%) | 30% | >= 80% | >= 100% |
| 时间达成 | RPO 达成率 | 实际RPO <= 目标RPO ? 100% : (目标/实际*100%) | 25% | >= 80% | >= 100% |
| 流程完整性 | 流程执行率 | 已执行步骤 / 应执行步骤 * 100% | 20% | >= 90% | 100% |
| 人员熟练度 | 平均操作时间 | 各步骤操作时间 vs 预计时间 | 15% | <= 150% | <= 100% |
| 预案有效性 | 预案缺陷数 | 演练中发现的预案缺陷数量 | 10% | <= 3个 | 0个 |

### 5.2 综合评分

| 评分等级 | 分数范围 | 定义 | 后续动作 |

| 优秀 | 90-100分 | 所有指标达到优秀标准 | 继续保持 |
| 良好 | 75-89分 | 大部分指标达标，少数需改进 | 针对性改进 |
| 合格 | 60-74分 | 基本达标，存在明显短板 | 制定改进计划并限期整改 |
| 不合格 | < 60分 | 多项指标未达标 | 立即整改，1个月内重新演练 |

### 8.2 演练安全注意事项

1. 演练必须在隔离环境中进行，严禁在生产环境中执行破坏性操作
2. 如需在生产环境演练（如流量影子模式），需经总指挥审批并制定回滚方案
3. 演练前需确认备份可用性，防止演练过程中真正发生数据丢失
4. 演练期间应通知所有相关人员，避免误判为真实故障
