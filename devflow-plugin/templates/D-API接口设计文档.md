## 2. 接口清单

### 2.1 {模块名}

| 接口 ID | 路径 | 方法 | 请求参数 | 响应说明 | 备注 |
|---------|------|------|---------|---------|------|
| API-001 | `/api/v1/{资源}` | GET | Query: {字段} | {响应结构简述} | {分页/缓存等} |
| API-002 | `/api/v1/{资源}` | POST | Body: {字段} | {响应结构简述} | {幂等性说明} |

#### 示例：API-001 `GET /api/v1/{资源}`

**请求参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | Integer | 否 | 页码，默认 1 |
| page_size | Integer | 否 | 每页条数，默认 20，最大 100 |
| keyword | String | 否 | 搜索关键字 |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [],
    "total": 0,
    "page": 1,
    "page_size": 20
  },
  "request_id": "uuid"
}
```

#### 示例：API-002 `POST /api/v1/{资源}`

**请求 Body：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | String | 是 | {资源名称}，长度 1-100 |
| description | String | 否 | {描述} |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": "uuid",
    "name": "{资源名称}",
    "created_at": "2026-01-01T00:00:00Z"
  },
  "request_id": "uuid"
}
```

## 3. 统一错误码表

| 错误码 | 说明 | HTTP 状态码 | 处理建议 |
|--------|------|------------|---------|
| 0 | 成功 | 200 | |
| 1001 | 参数校验失败 | 400 | 检查请求参数格式 |
| 1002 | 资源不存在 | 404 | 检查资源 ID 是否正确 |
| 1003 | 无权限 | 403 | 检查鉴权 Token |
| 1004 | 认证过期 | 401 | 刷新 Token 后重试 |
| 1005 | 请求频率过高 | 429 | 降低请求频率 |
| 2001 | 内部服务错误 | 500 | 联系运维 |
| 2002 | 第三方服务不可用 | 502 | 稍后重试 |
